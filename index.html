第 2 课:CSS —— 给网页穿衣服✅ 已毕业

核心语法(整个 CSS 就这一句话)

选择器 {
  属性: 值;
}

"选中谁,改成什么样"。例如 h1 { color: #1f6feb; } 表示所有 h1 文字变蓝。

选择器:怎么"选中"标签

选择器写法特点
标签选择器p { }命中所有 <p>
class 选择器.card { } + 标签挂 class="card"可复用,最常用

盒模型(唯一要"理解"的东西)

margin(外边距:和别人隔多远)
  └ border(边框)
      └ padding(内边距:内容和边框之间留多少)
          └ 内容

两个高频问题:文字太挤 → 加 padding 或 line-height;盒子水平居中 → max-width: 600px; + margin: 0 auto;

工作区(正在改的文件)
   │  git add    ← 放进"购物车"
   ▼
暂存区(准备提交的改动)
   │  git commit ← 结账存档,写备注
   ▼
本地仓库(历史存档)
   │  git push   ← 上传云端
   ▼
远程仓库(GitHub)

7 条命令(按顺序记)

命令作用
git init初始化仓库(每个项目一次)
git status看状态:改了什么、哪些没提交

改代码 → git add . → git commit -m "完成XX功能" → git push

if (itemInput.value === '') {   // 先检查空值

三个坑的详细解释

坑 1:第 6 行 Document 大写 → 整个程序"停摆"

document(小写)是浏览器给你的页面对象;大写 Document 不存在。JS 从上往下执行,这一行抛出 Uncaught ReferenceError: Document is not defined 后,后面的代码全部不会执行—— 所以你的计数器、添加功能其实从来没生效过。控制台里试一下:输入 document 有东西,输入 Document 直接报错。

坑 2:第 12 行 list.push(...) → 元素不是数组

list = document.querySelector('#list') 拿到的是页面上的 <ul> 元素——一个"盒子"。.push() 是数组的方法,盒子没有 → 报错 list.push is not a function。 往页面上"长"出新元素,永远用这三件套:

const li = document.createElement('li');  // ① 造一个新 li(打印一张纸)
li.textContent = itemInput.value;         // ② 往纸上写字
list.appendChild(li);                     // ③ 把纸贴到 <ul> 墙上

坑 3:第 13-16 行检查放太晚 + 用了 ==

if (itemInput.value === '') {   // 先检查
  alert('请输入待办事项');
  return;                        // return = 立即结束,下面不执行
}
// 通过检查,才执行:count++ / 三件套 / 清空输入框

另外:作业要求里还缺一个独立的"+1"按钮——你现在把"添加待办的次数"当成了计数,作业要的是一个按钮点一次 +1。HTML 里加 <button id="plusBtn">+1</button>,单独写它的监听(逻辑你其实已经会了:count++ + 更新显示)。

2026-09-02 · 学生提问:"不点添加就不能点完成,我的嵌套设计不是对的吗?"

你的直觉是对的:"没添加就不该能完成"——这是一条合理的业务规则,会想到规则层面,说明你在认真思考,这比抄作业强得多。

但"防"的方式错了:你用"把完成按钮的监听包在添加按钮的点击里(嵌套)"来防。问题在于:

  • 技术上:完成按钮的监听要等"添加"被点过一次才注册。打开页面什么都不点、直接点完成——没反应,因为监听根本不存在。结果碰巧符合你的预期,但这是"没注册",不是"规则拦截",控制台没有任何提示,以后排错会疯。
  • 可读性:两个按钮的代码纠缠在一起,几天后你自己都看不懂。

正确的防法:监听器永远平级注册,规则用 if 写在函数体里

// 两个监听都平级,谁都不包谁 —— 但它们内部各有规则
checkBtn.addEventListener('click', function () {
  if (tasks.length === 0) {          // 规则:还没添加过任务
    alert('还没有待办,先点添加');
    return;
  }
  // 完成逻辑...
});

addBtn.addEventListener('click', function () {
  if (input.value === '') { alert('请输入内容'); return; }
  // 添加逻辑...
});

这样"不能完成未添加的任务"照样成立,而且每个按钮的逻辑独立清晰。核心心法:事件监听 = 只负责"听到点击就执行函数";规则 = 函数体里的 if。

另外:作业 2 的原始要求只有两个功能(+1 计数、添加列表),"完成"按钮是你自己加的——你其实想做一个"添加→完成"的完整待办流程。这是更进阶的项目,需要用数组做状态记住"已添加的任务"。想学的话走路线 B(老师带做真流程),想先推进度走路线 A(按作业要求完成验收)。

2026-09-02 · CSS 的 cursor 和 border 是干嘛的

cursor:鼠标指针的样式。可点击元素(按钮/卡片/链接)加 cursor: pointer; 显示小手,提示"这个能点"。

button { cursor: pointer; }        // 小手
input  { cursor: text; }           // I 形光标(默认就有)
button:disabled { cursor: not-allowed; }  // 禁止符号

border:元素的边框,是盒模型的一层(margin → border → padding → 内容)。

.box { border: 2px solid #333; }   // 宽度 样式 颜色
h2 { border-left: 4px solid #1f6feb; }  // 只画左边(标题装饰)
// 样式: solid 实线 / dashed 虚线 / dotted 点线

调试神器:* { border: 1px solid red; } 给所有元素加红框,一眼看清每个盒子占多大。
